📊 Student Performance Analysis

An exploratory data analysis project using Python to examine student scores, study hours, and attendance.

🎯 Project Objective

The objective is to practice data cleaning, descriptive statistics, exploratory data analysis (EDA), and data visualization using a simulated student dataset.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

📁 Project Files

File| Description
"Student_Performance_Analysis.ipynb"| Notebook containing the analysis code, visualizations, and outputs
"student_performance.csv"| Dataset used in the analysis

🔍 Analysis Performed

- Generated a dataset of 120 simulated student records
- Checked dataset dimensions, data types, missing values, and duplicate rows
- Calculated descriptive statistics for subject scores
- Compared average performance across Mathematics, Science, and English
- Visualized score distributions and attendance versus average scores
- Examined correlations between study hours, attendance, and scores
- Generated a summary report and exported the dataset to CSV

📈 Tools and Concepts Practiced

- DataFrames and numerical operations
- Aggregation and descriptive statistics
- Histograms, bar charts, regression plots, and correlation heatmaps
- CSV export and reproducible random data generation

⚠️ Dataset Limitations

The dataset is synthetically generated for educational purposes. The scores are influenced by formulas that use study hours and attendance, along with random variation. Therefore, observed patterns and correlations should not be interpreted as evidence about real students or as proof of causation.

▶️ How to Run

1. Open "Student_Performance_Analysis.ipynb".
2. Download the notebook or open it in Google Colab.
3. Run the cells in order.
4. The dataset can be regenerated by running the data-generation cell.
